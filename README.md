# All Food

Aplicación móvil para la gestión de restaurante.

Stack tecnológico:

- Flutter (Android e iOS)
- Supabase

## Estado actual

Base inicial implementada:

- Pantalla de inicio de sesión
- Pantalla de registro
- Home vacío
- Cierre de sesión
- Inicialización de Supabase por variables de entorno


## Regla de Storage

Todas las fotos de productos, avatares y demas imagenes se almacenan en Supabase Storage.
En las tablas solo se guarda el enlace o path del archivo para luego cargarlo desde la app.
